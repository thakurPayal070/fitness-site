# FitPulse Fitness App  Page

FitPulse is a responsive product landing page for a fictional fitness
application. It was created with plain HTML, CSS, and JavaScript.

## Assignment Requirements Included

- Fixed navigation bar visible throughout the page
- Navigation background and styling change after scrolling
- Hover effects on navigation items
- Active navigation link changes while viewing each section
- Fully responsive desktop, tablet, and mobile layouts
- Mobile hamburger navigation
- HTML for structure, CSS for design, and JavaScript for interaction

## Extra Features

- Interactive workout category selector
- Monthly and yearly pricing switch
- Expandable FAQ section
- Product demonstration modal
- Scroll-reveal animations
- Back-to-top button
- Reduced-motion accessibility support

## Files

```text
index.html
style.css
script.js
README.md
```

## Run the Website

Download or clone the project and open `index.html` in a web browser. The
website does not need an installation, build command, or web server.

## Customize

The brand name, text, prices, links, and colors can be changed directly in the
three source files. The App Store and Google Play buttons are visual examples;
replace their `href` values with real application links if needed.
